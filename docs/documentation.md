# Documentation guide

[KiwiPi 4 product page](https://kiwipi.com/product/kiwipi-4/) · [Official resources](https://kiwipi.com/document-center/?dc_tab=10210.1)

## Hardware and first setup

Start with the [user manuals](https://drive.google.com/drive/folders/1ExJgLoRKsR0Wwq-AxdJqJvDF36xP0HA4) for power requirements, connector assignments and installation instructions applicable to your hardware revision.

Use the [schematics](https://drive.google.com/drive/folders/1WpojgzyHuOt9RQazk_iDlY1dSuuJE-ku) for electrical reference. Match the schematic revision to your board.

## Firmware installation

Choose a compatible image from [Downloads](downloads.md). Follow its firmware upgrade instructions and obtain tools from the [official development tools folder](https://drive.google.com/drive/folders/18vr3DqsFWyBDSbTwDpChkEEuO-eRdIOy).

## Software development

Obtain SDKs and source archives from the [official source folder](https://drive.google.com/drive/folders/1m6CwKkYOkMBASALPfkVV5kcmDcZ9a_b7). Follow the selected SDK's build instructions and component licenses.

## Support

For help identifying the correct manual, hardware revision or firmware image, [contact KiwiPi](https://kiwipi.com/contact-us/).
